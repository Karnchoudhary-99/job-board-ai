# Job Board with AI Matching

A job board in PHP with AI-powered candidate–job matching: job postings,
candidate profiles, and a transparent match score explaining why a
candidate fits a role.

> Status: scaffold only — job postings and candidate profiles next.

## Roadmap

- [x] Project scaffold (Composer, PHPUnit, CI, README)
- [ ] Job postings + candidate profiles
- [ ] AI matching engine (skill overlap, experience fit, explanations)
- [ ] Search, ranking and application flow
- [ ] Self-review checklist, then public

## Quick start

```sh
composer install
vendor/bin/phpunit
```
